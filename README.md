## Возможности

> Эти функции становятся доступны в билдере только при включённой автозагрузке.

* **Кейлоггер**:
  Включается при вводе текста в чатах или на сайтах банков.
* **Клиппер**:
  Перехватывает и подменяет адреса криптовалютных кошельков в буфере обмена при совершении транзакций.
* **Снимки с веб-камеры**:
  Делает снимки с веб-камеры при просмотре контента определенной категории.
* **Способы доставки отчётов**:
  Поддержка отправки через **Discord Webhook** или напрямую на **Email** (через встроенный SMTP/TempMail).
